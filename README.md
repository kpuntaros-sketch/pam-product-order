## Scroll fix
แก้ไขหน้าตะกร้าสินค้า:
- รายการสินค้าในตะกร้าสามารถ scroll ขึ้นลงได้
- ส่วนยอดรวมและปุ่มสร้างรายการสั่งซื้อติดอยู่ด้านล่าง
- รองรับกรณีมีสินค้าจำนวนมากในตะกร้า


## No LTP display
- ซ่อนราคา LTP จากหน้ารายการสินค้า
- ไม่กระทบ Offer Price, VAT, โปรโมชั่น, ตะกร้า หรือ Excel Export


## Export ประวัติ
เพิ่มปุ่ม `📚 Export ประวัติ` บนแถบด้านบนของหน้าเว็บ
- ดาวน์โหลดประวัติคำสั่งซื้อที่ถูกบันทึกใน browser เป็น Excel
- ใช้งานได้หลัง Login
- ประวัติเป็นข้อมูล localStorage ของ browser/เครื่องนั้น


## Average price per piece
เพิ่มคอลัมน์ `ราคาเฉลี่ยต่อชิ้น` ใน Excel Export

สูตรสำหรับรายการปกติ:
ยอดชำระ ÷ ((จำนวนซื้อ + ของแถมของรายการนั้น) × จำนวนชิ้นต่อแพ็ก)

หมายเหตุ: ของแถมจากโปรโมชั่นแบบรวมหลาย SKU จะถูกแสดงเป็นแถวของแถมแยกต่างหากใน Excel


## Average price history fix
แก้ปัญหา Export ประวัติเดิมแล้วคอลัมน์ `ราคาเฉลี่ยต่อชิ้น` เป็น 0
สาเหตุ: Order ที่บันทึกใน localStorage ก่อนเพิ่มฟีเจอร์นี้ไม่มีค่า avgPiecePrice
เวอร์ชันนี้จะคำนวณย้อนหลังขณะ Export จาก:
ยอดชำระ / ((จำนวนซื้อ + ของแถมรายสินค้า) × จำนวนชิ้นต่อแพ็ก)


## Average price fix v2
แก้ Export ประวัติแบบย้อนหลังโดยไม่พึ่งค่า `pack` หรือ `avgPiecePrice` ใน localStorage เก่า
ระบบจะค้นหา `จำนวนชิ้น/แพ็ก` จาก products.js ด้วย `itemNo` แล้วคำนวณ:
ราคาเฉลี่ยต่อชิ้น = ยอดชำระ / ((จำนวนซื้อ + ของแถมรายสินค้า) × จำนวนชิ้นต่อแพ็ก)
